# auth.md for AUMARA

## Public access
AUMARA's public website, FAQ, legal/policy pages, sitemap, llms.txt and API/resource catalog do not require authentication.

## Reservations
The public website does not expose an autonomous booking API. Direct reservations are completed in the external Beds24 booking interface at https://beds24.com/booking2.php?propid=324882.

## Agent behaviour
Automated clients may read public guest information subject to robots.txt, normal HTTP controls and rate limits. Do not infer an OAuth, privileged API, payment protocol or agent credential flow that is not explicitly published.
